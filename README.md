# Wizza Free Shop

Wizza Free Shop est une boutique digitale basée à Ouagadougou (Burkina Faso) permettant de vendre des produits numériques (packs de montage vidéo, LUTs, transitions, cours de formation football, etc.) à une communauté connectée via TikTok et WhatsApp.

---

## 🚀 Fonctionnalités

- Fil d’actualité façon Facebook (`index.js`)
- Vitrine produits en grille (`produit.js`)
- Page produit détaillé (`product/[id].js`)
- Pages Contact et Localisation
- Mentions légales conformes RGPD / CCPA
- Tableau de bord Admin sécurisé (`admin.js`)
- Authentification Supabase (email/mot de passe)
- Publication de produits via formulaire connecté à Supabase
- Design moderne (fond sombre, accents dorés)

---

## 🛠️ Technologies utilisées

- [Next.js](https://nextjs.org/) (React Framework)
- [Supabase](https://supabase.com/) (Base de données + Auth)
- [React](https://react.dev/)
- CSS Modules (styles personnalisés)
